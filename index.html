ตั้ง PIN เพื่อล็อกแท็บ คลังสินค้า, แดชบอร์ด, ตั้งค่า และเมนู เช็ค Stock ปิดวัน ไว้เฉพาะหลังบ้าน หน้าบ้านจะเข้าได้แค่ คิดเงิน, รับของเข้า และ ปิดร้าน เท่านั้น (เว้นว่างไว้ = ไม่ล็อก)

เชื่อมต่อฐานข้อมูล (Google Sheet)

1. สร้าง Google Sheet ใหม่ (ว่างเปล่าก็ได้)
2. เมนู Extensions → Apps Script
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ Code.gs ที่แนบมาให้
4. กด Deploy → New deployment → เลือกประเภท Web app
5. ตั้งค่า Execute as: Me, Who has access: Anyone → กด Deploy
6. คัดลอก Web app URL ที่ได้ มาวางด้านล่างนี้
